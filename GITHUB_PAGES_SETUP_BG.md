# BLE Meter — GitHub Pages (FLAT package)

Тази версия няма подпапки. Всички файлове се качват директно в root на repository `ble-meter`.

Качи наведнъж:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- .nojekyll
- README_BG.txt
- GITHUB_PAGES_SETUP_BG.md

След качването:
1. Commit changes
2. Settings -> Pages
3. Source: Deploy from a branch
4. Branch: main
5. Folder: / (root)
6. Save
