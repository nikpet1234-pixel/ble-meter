Качи/замени в GitHub ВСИЧКИ файлове от този ZIP.

След GitHub Pages deployment:
1. Деинсталирай старата BLE Meter инсталация/shortcut.
2. Chrome -> Settings -> Site settings -> All sites
3. nikpet1234-pixel.github.io -> Clear & reset / Clear data
4. Отвори:
   https://nikpet1234-pixel.github.io/ble-meter/
5. Refresh.
6. Използвай INSTALL APP, не само Create shortcut/Add shortcut.
7. Провери Settings -> Apps: трябва да има BLE Meter.

Ако BLE Meter НЕ се вижда в Settings -> Apps, Android е създал browser shortcut,
а не WebAPK. Shortcut-ите могат да имат браузърна значка/генерична икона.
